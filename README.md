# 일상처방 포토부스

2026 ATC × 일상처방 포토부스 웹 버전.

- 모자 쓴 새가 화면 전체를 날아다녀요.
- 라바콘은 중력 때문에 계란 바닥에 서 있어요.
- 라바콘 몸통에 손을 대고 **주먹을 쥐면** 잡혀요. 잡은 채로 움직이면 도장이 찍혀요.
- 손을 펴면 놓아요. 휘두르다 놓으면 그 방향으로 던져지고, 바닥에서 통통 튀다 멈춰요.

## 방식 (S 키로 전환)
1. 색연필: 라바콘을 잡고 움직이면 밑면을 따라 초록 색연필 선이 그려지고, 5초 뒤 사라져요.
2. 화면에 꾹: 라바콘을 쥔 손을 화면(카메라) 쪽으로 쑥 내밀 때마다 손 주변에 도장이 3~5개씩 흩어져 찍혀요. 다시 손을 당겼다가 내밀면 또 찍혀요. 이 방식으로 찍은 도장은 사라지지 않고, 오른쪽 아래 **도장 지우기** 버튼(또는 `C` 키)으로 지워요.

## 사진 찍기
`Enter`를 누르면 3초 카운트다운 뒤 화면 전체가 사진으로 찍혀요. 찍힌 사진은 Cloudinary에 올라가고, 화면에 뜨는 QR코드를 휴대폰으로 찍으면 받을 수 있어요. 설정은 `SETTINGS`의 `cloudName`, `uploadPreset`에서 바꿔요.

## 키
- `F` 전체화면
- `S` 도장 방식 전환 (`1`, `2`로 바로 고를 수도 있어요)
- `D` 손 인식 점 보기
- `C` 도장 지우기
- `Enter` 사진 찍기

크기·속도·중력·순서는 `index.html` 맨 위 `SETTINGS`에서 바꿀 수 있어요.
